**Introduction**

Bandit is a beginner-friendly wargame created by OverTheWire to teach the fundamentals of Linux, the Unix command line, SSH, file navigation, permissions, and basic security concepts through hands-on challenges.
Each level introduces a new command, concept, or problem-solving technique. The password obtained in one level is used to log into the next level.

**What is OverTheWire?**
OverTheWire is a collection of security wargames designed for learning cybersecurity and Linux skills in a practical way.

**Objectives of Bandit:-**
Learn essential Linux terminal commands.
Understand file and directory navigation.
Work with hidden files and unusual filenames.
Use SSH to connect to remote systems securely.
Read and search files using command-line utilities.
Understand file permissions and ownership.
Build confidence in solving terminal-based security challenges.
