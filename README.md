# OverTheWire Bandit Walkthrough (Levels 0–16)

This repository contains my beginner-friendly walkthrough for the **OverTheWire Bandit Wargame** (Levels **0–16**).

## What's Included

* Step-by-step walkthrough for each level.

* Commands explained in simple English.

* Key Linux concepts learned in every level.

* Important takeaways for quick revision.

* Windows Command Prompt / PowerShell login format.

## Topics Covered

* SSH login and authentication

* Linux file and directory commands

* Hidden files and special filenames

* `grep`, `sort`, `uniq`, `strings`

* Base64 decoding and ROT13

* `find` command with filters

* File type identification using `file`

* Compression and decompression (`gzip`, `bzip2`, `tar`)

* SSH private key authentication

* Networking with `nc` (Netcat)

* SSL/TLS connection using `openssl s_client`

## Purpose

These notes are written in a **minimal, beginner-friendly format** to make Bandit easy to understand and revise.
